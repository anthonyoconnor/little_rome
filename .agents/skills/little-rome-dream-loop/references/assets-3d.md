# 3D assets: use Blender

Use **Blender** to create and modify Little Rome's 3D models, materials, and animations. Prefer Blender's Python scripting interface for repeatable work.

Keep editable .blend sources and export browser-ready .glb files. Check scale, orientation, materials, and animation in the actual game after import.

Blender is installed locally at:

~~~text
C:\Program Files\Blender Foundation\Blender 5.2\blender.exe
~~~

Preparation verified Blender 5.2.1 LTS and its glTF export operator. Rediscover the executable if that path changes.
